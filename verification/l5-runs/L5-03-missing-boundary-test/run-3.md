## チェックリスト判定

| 項目 | 判定 | 理由 |
|---|---|---|
| 境界値 | **該当** | 閾値 `MEMBER_DISCOUNT_MIN_PRICE`（1000）の ちょうど / すぐ下 / すぐ上 の 3 テストが削除された。残るのは 2000（非会員）・1005・0 のみで、**閾値をまたぐ入力が一つもない** |
| 異常系 | 非該当 | 削除されたのは境界値テストで異常系ではない。`0` のケースは残存。負値 / 非整数 / NaN の未カバーは差分以前からの状態で、この差分が変えたものではない |
| 権限 | 非該当 | Controller / Guard に触れていない。差分はテストファイル 1 本のみ |
| 冪等性 | 非該当 | `applyDiscount` は副作用のない純関数。差分に状態変更の追加なし |
| 並行性 | 非該当 | 共有状態・同時更新に関わる変更なし |
| 障害時 | 非該当 | 外部サービス呼び出しに関わる変更なし |
| トランザクション境界 | 非該当 | DB 書き込みに関わる変更なし |

## 指摘

| 重大度 | ファイル:行 | 指摘 | 根拠 |
|---|---|---|---|
| 高 | `apps/api/src/discount/discount.spec.ts:8` | 会員割引の閾値境界（999 / 1000 / 1001）のテストが 3 件とも削除され、この仕様分岐が一切固定されなくなった | `discount.ts:13` の `price < MEMBER_DISCOUNT_MIN_PRICE` を `<=` に変えても、残存テストの入力（2000/非会員、1005、0）はどれも `price === 1000` を通らないため全て緑のまま。off-by-one が素通りする |
| 高 | `apps/api/src/discount/discount.spec.ts:8` | 削除により、閾値定数 `MEMBER_DISCOUNT_MIN_PRICE` 自体の値変更もテストで検知できない | 残存テストで割引が発動する入力は 1005 のみ。閾値を 1000→1005 に変えても全テストが通る。「割引の適用開始点」という仕様の中核が無防備 |
| 中 | `apps/api/src/discount/discount.spec.ts:8` | プロパティテストは境界の代替にならない | 残る 3 つのプロパティ（`result <= price` / 非会員不変 / 非負整数）はいずれも `<` を `<=` にしても、閾値を動かしても成立する。invariant であって仕様の分岐点を固定していない |

`import { MEMBER_DISCOUNT_MIN_PRICE }` の削除自体は、削除に伴う正しい後始末なので指摘しません（残せば lint が拾う範囲）。

修正案としては、削除された 3 ケースを戻すのが最小です。特に `applyDiscount(MEMBER_DISCOUNT_MIN_PRICE - 1, true) === 999` と `applyDiscount(MEMBER_DISCOUNT_MIN_PRICE, true) === 900` の 2 本が、境界の向き（以上か超過か）を一意に固定する最小セットになります。
